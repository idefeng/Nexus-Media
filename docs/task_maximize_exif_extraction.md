# 任务：改进 EXIF 提取与存储（最大化提取）

## 任务背景
根据 [标点符 - Python 获取图片 EXIF 信息](https://www.biaodianfu.com/exif-python.html) 的指导，我们需要最大化提取媒体文件的元数据。目前的实现已经使用了 `exiftool-vendored`（这是文章推荐的方案），但我们只提取了其中的一小部分字段。

## 修复/改进方案
1.  **扩展字段映射**：大幅增加从 `exiftool` 返回的对象中提取的字段数量，包括镜头信息、测光模式、白平衡、色彩空间、场景类型等。
2.  **Raw 数据存储**：在存储结构化字段的同时，将不常用的元数据也尝试保留，或者通过扩展 `ExifData` 接口包含更多细节。
3.  **支持更多格式**：确保提取逻辑能够处理来自不同相机厂商的特定标签（MakerNotes）。

## 预期结果
- 数据库 `exif_data` 字段将包含更丰富的 JSON 信息。
- 用户界面（如果已实现）能够展示更多摄影参数（如：镜头型号、测光方式等）。
